# 医院门诊信息管理系统

大一下「学术与工程实践」小学期课程作业。使用 C 语言实现的医院门诊业务管理命令行系统，涵盖医生信息维护、出诊排班、病人挂号、查询统计与汇总报表等门诊全流程。

- **语言**：C（标准文件读写 + 链表，无第三方依赖）
- **规模**：3,473 行（9 个 `.c` + 9 个 `.h`）
- **形态**：单文件存储 + 链表内存管理，编译为 `hospital.exe` 在 Windows 下运行
- **编写方式**：结合 AI 辅助开发，本人负责需求确认、数据结构设计、代码审查与编译测试

## 功能模块

程序主菜单共 9 项：

| 菜单 | 模块 | 说明 |
|---|---|---|
| 1 | 设置及修改密码 | 首次设置 / 修改系统密码，需验证旧密码 |
| 2 | 录入医生基本信息 | 录入编号、姓名、科室、挂号费、职称、是否专家、可挂号上限、备注 |
| 3 | 医生出诊信息的生成 | 依据医生信息生成某日出诊排班，挂号人数计数归零 |
| 4 | 病人门诊挂号管理 | 按单号格式 `YYYYMMDD+4位序号` 生成挂号单，校验号源并归档 |
| 5 | 修改医生基本信息 | 定位后逐字段修改 |
| 6 | 输出全部信息 | 医生 / 出诊 / 挂号三类信息，或全部输出 |
| 7 | 查询管理 | 医生、出诊、挂号三类查询 |
| 8 | 统计管理 | 按科室、姓名、日期、职称、是否专家分组统计，含字符柱状图 |
| 9 | 汇总报表 | 汇总输出 |
| 0 | 退出系统 | — |

### 查询条件

- **医生基本信息**：医生编号、姓名、科室、价格、职称、是否专家、可挂号人数（7 类）
- **医生出诊信息** / **病人挂号信息**：按对应业务字段组合查询

### 统计能力

- 按科室 / 姓名 / 日期 / 职称 / 是否专家分组统计
- 以字符柱状图（`*` 数量表示人数）在终端直观展示

## 数据设计

### 数据结构

| 结构体 | 存储文件 | 关键字段 |
|---|---|---|
| `DoctorBase` | `doctor_base.dat` | 编号、姓名、科室、挂号价格、职称、是否专家、可挂号上限、备注 |
| `DoctorDuty` | `doctor_duty.dat` | 出诊日期 + 从 `DoctorBase` 复制的基本信息 + 已挂号人数 |
| `Registration` | `register-sell.dat` | 挂号单号、日期、价格、医生信息、病人编号与姓名 |

四条链表的头指针统一封装在 `SystemManager` 结构体中，**通过函数参数传递，全局变量零使用**。

### 数据文件

| 文件 | 内容 |
|---|---|
| `pwd.dat` | 系统密码（XOR 加密存储） |
| `doctor_base.dat` | 医生基本信息 |
| `doctor_duty.dat` | 医生出诊信息 |
| `register-sell.dat` | 病人挂号信息 |
| `log.txt` | 操作日志 |

### 密码机制

- 长度限制 6–16 位
- XOR 加密后写入 `pwd.dat`（加解密共用同一函数）
- 登录最多 3 次机会，每次提示剩余次数，超限退出系统

## 编译与运行

`Makefile` 会自动探测编译器：

```bash
# 编译（自动选择 WSL2 交叉编译 / Windows MinGW / 本机 gcc）
make

# 运行
make run

# 清理产物
make clean
```

编译选项：

```makefile
CFLAGS = -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=GBK -static
```

`-fexec-charset=GBK` 是为适配 Windows 控制台的 GBK 编码；`-static` 生成静态链接的可执行文件，便于在无运行库的机器上直接双击运行。

> 编译器探测顺序：`x86_64-wingw32-gcc`（WSL2 交叉编译）→ `/mnt/c/mingw64/bin/…exe`（Windows MinGW）→ `gcc`（本机）。
